# Image Studio

一个面向小范围内测的文字生图工作台：用户输入描述、选择画幅，生成并下载图片；后续接入账号、点数包和支付。

当前仓库是第一阶段的可运行骨架，首页已经完成交互原型，数据库 schema 已定义用户、订单、生成任务和不可变点数账本。图片 API、登录和支付故意保留为下一阶段，`.env.example` 只提供配置占位符。

## 本地运行

要求 Node.js 22.17+ 和 pnpm。

```bash
pnpm install
pnpm dev
```

验证基础工程：

```bash
pnpm check
pnpm build
pnpm test
pnpm lint
```

初始化本地 SQLite 数据库：

```bash
pnpm db:init
```
